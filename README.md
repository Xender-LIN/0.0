### 公司特色

- **循環經濟**：運用再生環保系統技術，將廢棄物分離產生有價塑膠，加工造粒後銷售
- **智慧製造**：斥資逾 3 億元導入智慧化資訊系統及機械物聯網設備，打造一條龍產品履歷
- **ESG 永續**：推動碳盤查及 ESG 計畫，運用大數據及戰情中心監控七大製造部門
- **政府認可**：獲經濟部「中小企業加速投資行動方案」核准

## 專案概述

本專案為**泳鉅鑫再生塑料股份有限公司**規劃建置 B2B 電商網站，參考大陸「同益云商」(tongyicm.com) 平台架構，結合台灣在地化需求與**再生塑料/循環經濟**產業特性，打造集**企業官網、產品展示、線上交易、多供應商平台**於一體的綜合性再生塑膠原料電商平台。

## 參考對象

**同益云商 (tongyicm.com)** — 同益股份（深交所上市，代碼 300538）旗下化工高分子材料電商平台，主營 ABS、PC、POM 等工程塑料，合作 2000+ 品牌商，服務華為、小米、比亞迪、富士康等大客戶。

## 網站三大定位

1. **企業官網** — 泳鉅鑫品牌形象、再生塑料產品展示、詢價服務、ESG/循環經濟理念展示
2. **線上交易平台** — 購物車、下單、支付、訂單管理
3. **多供應商平台** — 供應商入駐、旗艦店、多源集采

## 再生塑料產業特殊需求

- **產品履歷追溯**：每批再生粒子的原料來源、加工流程、品質檢測報告
- **環保認證展示**：再生料含量比例、碳足跡數據、ESG 報告
- **品質檢測報告**：每批次 SGS/第三方檢測報告下載
- **碳排放計算器**：使用再生料相比新料可減少的碳排放量試算
