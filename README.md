# 塑膠原料 B2B 電商網站 — 專案提案

## 專案概述

本專案為台灣塑膠原料貿易公司規劃建置 B2B 電商網站，參考大陸「同益云商」(tongyicm.com) 平台架構，結合台灣在地化需求，打造集**企業官網、產品展示、線上交易、多供應商平台**於一體的綜合性塑膠原料電商平台。

## 參考對象

**同益云商 (tongyicm.com)** — 同益股份（深交所上市，代碼 300538）旗下化工高分子材料電商平台，主營 ABS、PC、POM 等工程塑料，合作 2000+ 品牌商，服務華為、小米、比亞迪、富士康等大客戶。

## 網站三大定位

1. **企業官網** — 公司品牌形象、產品展示、詢價服務
2. **線上交易平台** — 購物車、下單、支付、訂單管理
3. **多供應商平台** — 供應商入駐、旗艦店、多源集采
