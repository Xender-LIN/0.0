## 5. SEO 路由設計原則 (SEO-Friendly URL Design)

| 原則 | 說明 | 範例 |
|------|------|------|
| **kebab-case** | URL 使用小寫連字號 | `/products/abs-chimei-pa757` |
| **語意化** | 路徑有意義，反映內容 | `/brands/chimei` |
| **避免深層巢狀** | 最多 3 層 | `/products/{slug}` |
| **避免參數** | Query 僅用於篩選/排序 | `/products?category=abs&brand=chimei` |
| **Canonical URL** | 避免重複內容 | `<link rel="canonical">` |
| **多語言** | i18n 路由 | `/en/products/...` |
