# 功能規格書 (Feature Specification)

> Functional Requirements for 泳鉅鑫再生塑料 B2B E-Commerce Platform

---

## 1. 功能總覽 (Feature Overview)

本平台為**泳鉅鑫再生塑料股份有限公司**建置，整合三大定位：**企業官網**、**線上交易平台**、**多供應商平台**，並特別強調**再生塑料/循環經濟**產業特性，以下依模組詳列功能規格。

### 功能模組地圖

```
┌─────────────────────────────────────────────────────┐
│                    前台 (Frontend)                    │
├──────────┬──────────┬──────────┬────────────────────┤
│  企業官網  │  產品中心  │  交易系統  │  供應商平台        │
│  - 首頁   │  - 目錄   │  - 購物車  │  - 供應商入駐      │
│  - 關於   │  - 詳情   │  - 結帳   │  - 旗艦店         │
│  - 新聞   │  - 搜尋   │  - 訂單   │  - 多源集采        │
│  - 聯絡   │  - 品牌   │  - 詢價   │  - 供應商後台      │
├──────────┴──────────┴──────────┴────────────────────┤
│                 會員系統 (Member System)               │
│  - 註冊/登入 - 企業認證 - 個人中心 - 收藏/常購          │

│  - 即時報價 - 價格走勢 - 市場資訊 - 價格訂閱             │

│  - 產品管理 - 訂單管理 - 會員管理 - CMS - 數據報表       │

```

## 4. 交易系統 (Transaction System)

### 4.1 詢價/報價流程 (RFQ System)

```
買家填寫詢價表單 → 系統通知業務 → 業務回覆報價
→ 買家確認 → 轉為訂單 → 出貨 → 完成
```

| 功能 | 描述 | 優先級 |
|------|------|--------|
| **詢價表單** | 產品、數量、交貨地點、期望交期 | P0 |
| **批量詢價** | 一次詢問多項產品 | P1 |
| **報價回覆** | 業務後台回覆報價，買家收到通知 | P0 |
| **報價有效期** | 設定報價有效天數 | P1 |
| **確認下單** | 買家確認報價後轉為正式訂單 | P0 |

### 4.2 購物車與結帳

| 功能 | 描述 | 優先級 |
|------|------|--------|
| **購物車** | 新增/移除產品、修改數量 | P1 |
| **運費計算** | 依地區/重量計算 | P1 |
| **收貨地址管理** | 多組地址儲存 | P1 |
| **結帳** | 確認訂單內容、選擇支付方式 | P1 |

### 4.3 支付方式（台灣在地化）

| 方式 | 描述 | 優先級 |
|------|------|--------|
| **銀行轉帳** | 提供公司銀行帳號，匯款後回報 | P0 |
| **LINE Pay** | 整合 LINE Pay API | P2 |
| **信用卡** | 整合第三方金流（綠界/藍新） | P2 |
| **月結帳款** | 信用客戶月結付款 | P1 |

### 4.4 訂單管理

| 功能 | 描述 | 優先級 |
|------|------|--------|
| **訂單狀態** | 待確認 → 已確認 → 備貨中 → 已出貨 → 已完成 | P0 |
| **出貨通知** | Email / LINE 推播出貨通知 | P1 |
| **物流追蹤** | 整合物流商 API 追蹤貨態 | P2 |
| **電子發票** | 符合台灣財政部電子發票規範 | P1 |

## 7. 非功能性需求 (Non-Functional Requirements)

| 項目 | 規格 |
|------|------|
| **效能** | 頁面載入時間 < 3 秒（台灣地區） |
| **可用性** | 99.9% uptime SLA |
| **安全性** | HTTPS、SQL Injection 防護、XSS 防護、CSRF Token |
| **個資保護** | 符合台灣個人資料保護法 |
| **RWD** | 支援桌面、平板、手機自適應 |
| **瀏覽器** | Chrome、Safari、Edge、Firefox 最新兩版本 |
| **SEO** | Server-Side Rendering、Sitemap、Schema Markup |
| **多語言** | 繁體中文（預設）+ 英文 |
| **無障礙** | 基本 WCAG 2.1 AA 合規 |

## 9. 再生塑料產業專屬功能 (Recycled Plastics Specific Features)
