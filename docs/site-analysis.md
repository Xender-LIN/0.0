## 2. URL 結構與頁面層級 (URL Structure & Page Hierarchy)

### 2.1 已確認的 URL 路徑

| 頁面名稱 | URL 路徑 | 說明 |
|----------|----------|------|
| 首頁 | `/` | 平台入口，搜尋、推薦商品、行情 |
| 產品詳情 | `/ProductDetails/{id}` | 如 `/ProductDetails/511`（ABS 台灣奇美 PA-757）|
| 產品詳情 (HTML) | `/ProductDetails/{id}.html` | 如 `/ProductDetails/677.html` |
| 購物車 | `/ShoppingCart` | 購物車頁面 |
| 旗艦店 | `/tyShop` | 品牌旗艦店入口 |
| 雲商動態 | `/Cloud.html` | 新聞與公告列表 |
| 新聞詳情 | `/NewsDetails/{id}.html` | 如 `/NewsDetails/50389.html` |
| 多源集采 | `/Businessmodel/MultiSource` | 業務模式 — 集中採購 |
| 倉儲金融 | `/Businessmodel/WarehousingFinance` | 業務模式 — 供應鏈金融 |
| 開放平台 API | `/Businessmodel/API` | 第三方系統對接 |

### 2.2 URL 命名規則分析

- **PascalCase 命名**：`/ProductDetails`、`/ShoppingCart`、`/NewsDetails`
- **業務模式子路徑**：`/Businessmodel/{功能名}`
- **ID 路由**：產品與新聞用數字 ID（如 `/511`、`/50389.html`）
- **混合使用**：部分頁面帶 `.html` 後綴，部分不帶

## 5. 技術觀察 (Technical Observations)

| 項目 | 分析 |
|------|------|
| **前端框架** | SPA（Single Page Application）架構跡象，URL 結構無傳統 `.aspx`/`.php` |
| **路由方式** | 前端路由 + 後端 API，PascalCase 路徑命名 |
| **防爬機制** | 403 Forbidden（有 WAF / CDN 防護）|
| **SEO 策略** | 部分頁面帶 `.html` 後綴以利搜尋引擎收錄 |
| **品牌商數量** | 2000+ 合作品牌，表示後端需強大的供應商管理系統 |
| **自營物流** | 擁有自營存儲物流體系 |

```
                    ┌─────────────────┐

                    └────────┬────────┘
                             │
```

**營收模式**：
1. 自營貿易差價
2. 平台交易佣金（供應商入駐）
3. 供應鏈金融服務費
4. API / 數據服務

## 7. 可借鏡的重點 (Key Takeaways for Taiwan Project)

### 值得參考
- 清晰的產品分類體系（按材料類型 → 品牌 → 型號）
- 多元業務模式（自營 + 平台 + 金融服務）
- 旗艦店機制讓供應商有品牌展示空間
- 開放 API 支援 ERP 系統對接

### 需要調整
- 支付方式需改為台灣在地（LINE Pay、銀行轉帳）
- 小程式改為 LINE LIFF / PWA
- URL 結構建議改用 kebab-case 以利 SEO
- 增加繁體中文 + 英文雙語支援
- 符合台灣法規（個資法、電子發票）
