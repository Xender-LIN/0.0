# 開發階段規劃 (Development Phases)

> 泳鉅鑫再生塑料 — Phased Implementation Roadmap

---

## 總覽 (Overview)

本專案採四階段漸進式開發，從 MVP 到完整平台逐步建置：

```
Phase 1          Phase 2          Phase 3          Phase 4
MVP 企業官網      交易功能上線       供應商平台         生態擴展
──────────── → ──────────── → ──────────── → ────────────
產品展示+詢價     購物車+訂單+支付   供應商入駐+旗艦店   API+金融+App
```

## Phase 1 — MVP 企業官網 + 詢價系統

> Minimum Viable Product: Corporate Website + RFQ System

### 目標
- 建立公司品牌形象網站
- 產品目錄上線，支援線上詢價
- 基本會員與後台管理功能

### 功能清單

| 模組 | 功能 | 說明 |
|------|------|------|
| **首頁** | Banner 輪播 | 可後台更換的形象圖 |
| | 產品分類入口 | 材料類型卡片式入口 |
| | 熱門產品推薦 | 後台設定推薦產品 |
| | 最新消息 | 最新 3-5 則新聞 |
| **產品中心** | 產品目錄頁 | 分類瀏覽、搜尋、篩選 |
| | 產品詳情頁 | 規格參數、TDS 下載、詢價 |
| **詢價系統** | 詢價表單 | 產品+數量+需求說明 |
| | 詢價通知 | Email 通知業務人員 |
| **新聞資訊** | 新聞列表/詳情 | 產業新聞、公司動態 |
| **企業頁面** | 關於我們 | 公司簡介、服務優勢 |
| | 聯絡我們 | 表單、地圖、聯絡方式 |
| **會員系統** | 註冊/登入 | 企業會員、Email 驗證 |
| | 個人中心 | 基本帳號資料、詢價紀錄 |
| **後台管理** | 產品管理 | CRUD、分類、品牌管理 |
| | 新聞管理 | 新增/編輯/發布新聞 |
| | Banner 管理 | 輪播圖管理 |
| | 詢價管理 | 查看/回覆詢價 |
| | 會員管理 | 查看會員列表 |
| **基礎建設** | RWD 響應式 | 桌面+手機自適應 |
| | SEO 基礎 | SSR、Meta Tags、Sitemap |
| | Google Analytics | 流量追蹤 |

### 技術里程碑

```
Week 1-2:  環境建置、DB 設計、UI 設計稿確認
Week 3-4:  首頁、產品目錄/詳情頁開發
Week 5-6:  會員系統、詢價功能、企業頁面
Week 7-8:  後台管理系統
Week 9-10: 整合測試、SEO 優化、上線部署
```

### 交付項目
- 前台網站（首頁 + 產品 + 詢價 + 新聞 + 企業頁面）
- 後台管理系統
- 會員系統
- 部署至正式環境
- 操作手冊

## Phase 2 — 線上交易功能

> E-Commerce Transaction System

### 目標
- 完成線上購物車與下單流程
- 整合台灣在地金流與電子發票
- 訂單全流程管理

### 功能清單

| 模組 | 功能 | 說明 |
|------|------|------|
| **購物車** | 加入/移除產品 | 數量調整、清空 |
| | 運費計算 | 依配送地區/重量 |
| **結帳流程** | 收貨地址 | 多組地址管理 |
| | 選擇支付方式 | 轉帳/信用卡/月結 |
| | 訂單確認 | 確認後送出訂單 |
| **金流整合** | 銀行轉帳 | 虛擬帳號/匯款回報 |
| | 信用卡 | 綠界/藍新金流串接 |
| | 月結帳款 | 信用客戶帳期管理 |
| **電子發票** | 發票開立 | 串接財政部電子發票 |
| | 發票管理 | 作廢、折讓 |
| **訂單管理** | 訂單狀態流程 | 待確認→備貨→出貨→完成 |
| | 出貨通知 | Email + LINE 推播 |
| | 後台訂單管理 | 審核、出貨、退換貨 |
| **報價強化** | 報價回覆 | 業務回覆報價金額 |
| | 報價轉訂單 | 確認報價一鍵轉訂單 |
| | 報價有效期 | 自動過期提醒 |
| **通知系統** | Email 通知 | 訂單狀態變更通知 |
| | LINE 通知 | LINE Messaging API 推播 |

### 技術里程碑

```
Week 1-2:  購物車功能、結帳流程
Week 3-4:  金流串接（綠界/藍新）、支付測試
Week 5-6:  訂單管理系統、出貨流程
Week 7-8:  電子發票串接、LINE 通知
Week 9-10: 整合測試、金流壓力測試、上線
```

### 交付項目
- 完整購物車與結帳流程
- 金流整合（銀行轉帳 + 信用卡）
- 電子發票系統
- 訂單管理後台
- LINE 通知功能

## Phase 3 — 供應商平台 + 進階功能

> Multi-Vendor Platform & Advanced Features

### 目標
- 開放供應商入駐，建立多賣家平台
- 行情中心上線
- 品牌旗艦店機制

### 功能清單

| 模組 | 功能 | 說明 |
|------|------|------|
| **供應商入駐** | 入駐申請 | 線上填寫企業資訊 |
| | 資質審核 | 營業登記、ISO 驗證 |
| | 供應商後台 | 商品管理、訂單處理 |
| **旗艦店** | 店面頁面 | 供應商專屬品牌頁 |
| | 店面裝修 | 自訂 Banner、介紹 |
| **行情中心** | 即時報價 | 主要原料每日報價 |
| | 價格走勢圖 | 30/90/365 天趨勢 |
| | 價格訂閱 | 訂閱特定材料通知 |
| | 行情分析 | 市場分析文章 |
| **多源集采** | 需求發布 | 買家發布採購需求 |
| | 供應商競標 | 多家報價比較 |
| **進階會員** | 企業認證 | 進階認證、信用評等 |
| | 常購清單 | 快速重購 |
| | 收藏管理 | 產品收藏 |
| **數據報表** | 銷售統計 | 營收、訂單數趨勢 |
| | 產品分析 | 熱門產品、瀏覽排行 |
| | 客戶分析 | 採購偏好、RFM 分析 |
| **物流整合** | 物流追蹤 | 串接物流商 API |
| | 出貨管理 | 批次出貨、列印出貨單 |

### 技術里程碑

```
Week 1-3:  供應商入駐系統、供應商後台
Week 4-6:  旗艦店機制、多源集采
Week 7-9:  行情中心、價格走勢圖
Week 10-12: 數據報表、物流整合、測試上線
```

### 交付項目
- 供應商入駐與管理系統
- 品牌旗艦店功能
- 行情中心（報價 + 走勢圖）
- 多源集采機制
- 數據分析報表
- 物流追蹤整合

## Phase 4 — 生態擴展

> Ecosystem Expansion

### 目標
- 開放 API 供 ERP 系統對接
- 英文版上線拓展國際市場
- 供應鏈金融服務
- LINE LIFF Mini App

### 功能清單

| 模組 | 功能 | 說明 |
|------|------|------|
| **開放 API** | RESTful API | 產品、訂單、庫存 API |
| | API Key 管理 | 第三方系統認證 |
| | API 文件 | Swagger 文件 |
| | Webhook | 訂單/庫存事件回呼 |
| **多語言** | 英文版 | 全站英文翻譯 |
| | 語言切換 | 前台自由切換 |
| **供應鏈金融** | 倉單融資 | 庫存作為擔保融資 |
| | 帳期管理 | 靈活信用帳期 |
| | 應收帳款融資 | 訂單融資服務 |
| **LINE LIFF** | Mini App | LINE 內嵌 Web App |
| | 快速下單 | LINE 內瀏覽+下單 |
| | 推播通知 | 行情/訂單 LINE 推播 |
| **AI 功能** | 智能推薦 | 基於採購歷史推薦 |
| | 智能搜尋 | 自然語言產品搜尋 |
| | 價格預測 | 原料價格趨勢預測 |

### 技術里程碑

```
Week 1-3:  開放 API 開發、文件撰寫
Week 4-6:  多語言（英文版）
Week 7-9:  LINE LIFF Mini App
Week 10-12: 供應鏈金融模組、AI 功能 POC
```

### 交付項目
- 開放 API + 文件
- 英文版網站
- LINE LIFF Mini App
- 供應鏈金融基礎模組
- AI 推薦/搜尋 POC

| 項目 | Phase 1 | Phase 2 | Phase 3 | Phase 4 |
|------|---------|---------|---------|---------|
| **前端開發** | 中 | 中 | 高 | 高 |

## 風險與對策 (Risks & Mitigation)

| 風險 | 影響 | 對策 |
|------|------|------|
| 金流串接延遲 | Phase 2 上線延期 | 提前申請金流帳號、Phase 1 先用銀行轉帳 |
| 供應商入駐意願低 | Phase 3 效果不佳 | 初期優惠政策、提供數位化轉型輔導 |
| 行情數據來源 | 數據不準確 | 多來源交叉驗證、初期人工更新 |
| 法規合規 | 罰則 | Phase 1 即導入電子發票、個資保護 |
| 效能瓶頸 | 使用體驗差 | 監控+預警、CDN 加速、DB 優化 |
