# 再生PC顆粒行銷戰役總覽

**公司：** 泳鉅鑫再生塑料股份有限公司（台灣）
**目標：** 銷售再生PC顆粒 ＋ 採購PC粗料/粉碎料
**市場：** 中國大陸18個塑料市場 ＋ 國際市場（東南亞/歐洲/中東/南亞）
**執行地：** 台灣（全程遠端）
**更新日期：** 2026-03

---

## 一、戰役架構

```
雙向行銷戰役
├── 銷售端：將再生PC顆粒賣給工廠採購商、貿易商
│   ├── 渠道A：微信私信開發（wechat_sales_outreach.md）
│   ├── 渠道B：電郵群發序列（email_sales_sequences.md）
│   ├── 渠道C：簡訊觸達（sms_sales_templates.md）
│   ├── 渠道D：B2B平台上架（b2b_sales_listings.md）
│   ├── 渠道E：WhatsApp/LinkedIn國際觸達（whatsapp_linkedin.md）
│   └── 渠道F：抖音短視頻（douyin_script.md）
│
└── 採購端：從各市場採購PC粗料/粉碎料作為生產原料
    ├── 渠道A：微信私信收料（wechat_procurement_outreach.md）
    ├── 渠道B：電郵收料序列（email_procurement_sequences.md）
    ├── 渠道C：收料簡訊（sms_procurement_templates.md）
    ├── 渠道D：B2B求購帖（b2b_procurement_listings.md）
    └── 渠道E：WhatsApp國際收料（whatsapp_linkedin.md）
```

## 二、30天行動計劃（數字基礎建設期）

### 第1週：帳號與平台建立

| 任務 | 說明 | 優先度 |
|------|------|--------|
| 建立1688企業店鋪 | 上架4個等級再生PC顆粒 + 發布求購PC廢料帖 | ★★★ |
| 建立阿里巴巴國際站 | 英文版產品上架（國際買家） | ★★★ |
| 建立抖音企業帳號 | 按 `douyin_script.md` 規格設置帳號簡介 | ★★ |
| 建立/確認業務微信號 | 專用業務微信號，不用私人微信 | ★★★ |
| 填入佔位符 | 將本套素材中所有 [PLACEHOLDER] 替換為實際數據 | ★★★ |

### 第2週：國內B2B平台鋪設

| 任務 | 說明 |
|------|------|
| 慧聰網企業入駐 | 上架產品 + 發布求購信息 |
| 中塑在線供應信息發布 | 每週更新行情價格 |
| 廢塑料之家 | 銷售供貨 + 求購PC廢料 同時發布 |
| 易塑網 | 供應信息發布 |

### 第3週：第一波微信/郵件名單建立

| 任務 | 說明 |
|------|------|
| 從1688收集買家名單 | 每個目標市場搜索10-20個潛在買家 |
| 從天眼查收集供應商名單 | 每個市場搜索廢塑料/再生塑料企業 |
| 向行業協會發介紹函 | 使用 `email_sales_sequences.md` 末尾的協會模板 |
| 建立CRM追蹤表 | 用Excel或Notion記錄每個聯繫人狀態 |

### 第4週：拍攝抖音視頻

| 任務 | 說明 |
|------|------|
| 拍攝視頻一（銷售版） | 按 `douyin_script.md` 視頻一腳本 |
| 拍攝視頻二（收料版） | 按 `douyin_script.md` 視頻二腳本 |
| 發布並觀察數據 | 發布後48小時看播放量和互動率 |
