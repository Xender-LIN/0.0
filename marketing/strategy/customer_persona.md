### 銷售畫像 S1｜工廠採購主管

**代表人物：** 王明輝，35-45歲，廣東東莞某電子配件廠採購部主管

**日常工作**
- 管理5-10個主要原料供應商
- 每月對採購成本負責，有壓低原料成本的績效指標
- 每季度向老闆匯報供應鏈狀況

**核心痛點**
- 原生PC太貴，但再生料品質不穩定（批次差異大）
- 老板要求做ESG/綠色供應鏈，但找不到有文件的再生料
- 換供應商要重新驗廠，麻煩且有風險
- 之前用過爛再生料導致廢品率上升，被老闆罵

**資訊獲取渠道**
- 1688/阿里巴巴找供應商
- 微信群（同行採購群）
- 展會（廣州電子展、余姚塑料博覽會）

**決策流程**
```
自己發現供應商 → 要樣品 → 打樣測試（1-2週）→ 送老闆審批 → 試訂一小批 → 穩定後增量
```

**關鍵顧慮**
- 「你這料會不會做著做著不穩定？」
- 「SGS報告是你們自己開的還是真的第三方？」
- 「我這邊量不大，你們會不會嫌小不理我？」

**我們的對應話術**
- 強調：每批獨立SGS（非自測）+ 批次追溯系統
- 提供：免費5kg樣品，降低試用風險
- 承諾：3噸起訂，小單也認真做

### 銷售畫像 S2｜塑料貿易商老闆

**代表人物：** 李春生，40-55歲，浙江余姚中國塑料城內做再生料的老闆

**日常工作**
- 在市場內租店面，從廠家批貨再賣給周邊工廠
- 自己就是老闆，決策快，看利潤空間

**核心痛點**
- 客戶越來越多要「有報告」的料，但市場上大多數再生料沒有檢測
- 競爭激烈，純靠價格越來越難做
- 台灣料有「品質背書」，可以多賣幾百元/噸

**資訊獲取渠道**
- 市場內同行口碑（最重要）
- 微信群
- 1688掃貨

**決策流程**
```
朋友介紹/主動了解 → 問價格（非常快）→ 試一批（5-10噸）→ 如果下游認可，持續拿貨
```

**關鍵顧慮**
- 「你這台灣料比大陸料貴多少？我的客戶能接受嗎？」
- 「貨期多長？我客戶等不了太久」
- 「能不能給我獨家？我在市場裡不想被人搶客戶」

**我們的對應話術**
- 強調：台灣品質 = 可賣更高價格，利潤更好
- 提供：現貨信息第一時間推送，讓他有搶先報價優勢
- 討論：區域獨家合作可能性

### 銷售畫像 S3｜ESG/出口導向企業採購

**代表人物：** 張曉梅，30-40歲，廣西梧州進口料加工園區或出口型製造商的採購

**日常工作**
- 公司有歐美客戶，客戶要求提供再生料認證和碳足迹報告
- 需要配合公司的ESG年報編制

**核心痛點**
- 國內再生料供應商幾乎沒有LCA報告、碳足迹證明
- 歐盟市場2025年後對再生含量有更嚴格要求
- 找不到能提供完整合規文件的再生料供應商

**資訊獲取渠道**
- 行業展會（廣交會、慕尼黑展）
- LinkedIn（尋找國際供應商）
- 郵件（習慣用郵件溝通）

**關鍵顧慮**
- 「你們的再生含量100%，有RCS認證嗎？」
- 「碳足迹是哪個機構算的？能配合我們的ESG審計嗎？」
- 「文件能用英文提供嗎？」

**我們的對應話術**
- 提供：完整ESG文件包（LCA + RCS + 碳足迹 + RoHS + REACH）
- 強調：台灣品質對標歐盟進口標準
- 支持：英文文件，配合國際審計

### 採購畫像 P1｜廢料收集貿易商

**代表人物：** 陳老闆，45-60歲，河北文安或廣東樟木頭做廢塑料貿易

**日常工作**
- 從工廠、拆解廠、回收站收廢料，分揀後賣給再生塑料廠
- 自己判斷料的品質，憑經驗定價

**核心痛點**
- 收來的料賣給本地廠家，PC料沒人出好價格
- 本地買家會壓級（說含量低、雜質多），台灣廠家會不會一樣？
- 跨境賣貨物流複雜，之前沒做過，不懂流程

**我們的對應策略**
- 強調：SGS客觀檢測，不是我們說了算，結果你看得到
- 提供：跨境物流幫助，降低他的操作複雜度
- 第一次合作：小批量先試（1-2噸），讓他建立信心

### 採購畫像 P2｜電子/家電廠廢料部門

**代表人物：** 吳工，廣東東莞電子廠環境/總務部門主管

**日常工作**
- 負責工廠生產廢料的合規處置
- 有環保審計壓力，需要廢料流向合規、有記錄
- 每月廢料有一定產量，賣給廢料商但覺得價格低

**核心痛點**
- 工廠PC邊角料品質好（純PC，含量高），但廢料商不懂分揀，出的價格按普通廢料算
- 需要有合規的廢料處置合同，配合環保巡查
- 不想麻煩，最好有人來廠取貨

**我們的對應策略**
- 強調：電子級PC邊角料比市場價高10-15%（因為品質好）
- 提供：正規收購合同、廢料流向記錄
- 服務：安排貨代上門提貨，不麻煩工廠物流部門

### 採購畫像 P3｜廢料回收園區企業

**代表人物：** 政府型园區內的分揀加工企業

**日常工作**
- 接受各類廢塑料，進行分揀、粉碎、初加工
- 有政府補貼，但出貨價格沒有競爭力（本地買家壓價）
- 希望找到出口渠道（台灣採購）

**核心痛點**
- 本地廠家對PC料了解不多，出的價格低
- 對跨境出口不熟悉，怕麻煩和風險
- 需要長期穩定買家（政府項目需要合同和記錄）

**我們的對應策略**
- 強調：台灣採購比大陸本地高[PREMIUM]%，直接增加企業收益
- 提供：正規採購合同，配合政府審計需求
- 長期框架協議：每月固定採購，幫助園區規劃廢料出貨計劃
