# 遠端進入各市場的方法（台灣遠端，不需地推）

> 目標：在不親赴大陸的情況下，精準觸及18個市場的買家和供應商
> 工具：1688、天眼查、企查查、行業協會、微信群、抖音

---

## 一、用1688找精準聯繫人

### 銷售端（找買家）
1. 搜索關鍵詞：`再生PC顆粒`、`PC再生料`、`聚碳酸酯再生料`
2. 篩選：**買家求購**頁面 → 看「求購信息」
3. 按地區篩選到18個目標城市（廊坊/余姚/東莞/佛山等）
4. 點擊每條求購信息 → 點「聯繫買家」→ 轉到旺旺或手機號
5. 用 `wechat_sales_outreach.md` 中的腳本聯繫

### 採購端（找供應商）
1. 搜索：`PC粗料`、`PC廢料`、`聚碳酸酯廢料`、`PC粉碎料`
2. 找**供貨**頁面 → 查看各市場賣家
3. 按地區篩選18個目標市場
4. 聯繫賣家，用 `wechat_procurement_outreach.md` 腳本
5. 每天目標：聯繫10-20個供應商

### 1688搜索技巧
```
有效關鍵詞組合：
- 「PC廢料 文安」（市場+品種）
- 「再生PC 余姚」
- 「PC粗料 東莞」
- 「聚碳酸酯粉碎料 佛山」
- 「PC邊角料 長葛」
```

## 二、用天眼查/企查查找企業名單

### 操作步驟
1. 打開天眼查 (tianyancha.com) 或企查查 (qichacha.com)
2. 搜索「再生塑料」+ 目標城市
3. 篩選條件：
   - 企業規模：小微/中小企業（個人：廢料商；中小：工廠採購）
   - 成立時間：2010年至今（太老可能已倒閉）
   - 經營狀態：存續
4. 導出企業名單（部分功能需付費會員）
5. 從企業詳情頁獲取：聯繫電話、法人姓名、主要產品

## 四、微信群找精準客戶

### 如何進入塑料行業微信群
1. **通過1688聯繫人邀請**：主動開發後，請對方拉你進行業群
2. **通過抖音評論區**：關注塑料行業大V，在評論區留言，等群邀請
3. **通過協會**：加入協會後，協會一般有會員微信群
4. **搜索關鍵詞**：微信搜索「PC料群」「塑料行情群」「再生料交流群」

### 進群後的操作規範
```
進群後先做自我介紹（勿直接發廣告，會被踢）：

「大家好！我是泳鉅鑫再生塑料的[YOUR_NAME]，台灣廠家，
主要做再生PC顆粒，也長期收購PC粗料/粉碎料。
有業務往來的歡迎私聊，不打擾大家，先潛水學習😊」
```

- 前2週：只看不發，了解群內話題和價格信息
- 第3週起：在行情討論時適時發言（分享行情信息，不推銷）
- 每週一次：發本週收購/銷售價格（純信息，不硬廣）
- 有詢盤時：私信回覆，不在群內搶單

## 五、樣品快遞策略（台灣→大陸）

### 推薦方式
| 快遞公司 | 台灣→大陸時效 | 費用（約）| 建議場景 |
|---------|-------------|---------|---------|
| 順豐速運（跨境）| 3-5個工作天 | NT$500-800/5kg | 首選，時效快，追蹤可靠 |
| DHL/FedEx | 3-5個工作天 | USD 30-60/5kg | 國際買家首選 |
| 台灣郵政EMS | 7-10個工作天 | NT$300-500/5kg | 成本敏感時用 |

### 樣品包裝清單
- 樣品袋：5kg密封PE袋，標明等級、批號、MFI、顏色
- 附件：SGS檢測報告影本（A4紙）、產品規格書（雙語）、名片
- 外箱：紙箱，貼「塑料顆粒樣品—非商業用途」標籤

### 報關備注
- 申報品名：Plastic Pellet Sample（塑料顆粒樣品）
- 申報價值：5kg樣品申報 USD 5（低報樣品價值，正常做法）
- 注意：每次寄樣不超過10kg，避免觸發進口稅審查

## 六、找當地代理商（長期合作）

### 代理商類型
1. **市場內的貿易商**：已在目標市場紮根，有現成客戶網絡
2. **行業老手/退休業務**：有人脈但願意做佣金制合作
3. **小型料商**：願意作為獨家經銷商，自行開發下游

### 代理商發展步驟
1. 先以客戶身份接觸（買少量樣品），建立信任
2. 確認對方有真實客戶基礎（詢問客戶類型/月走量）
3. 提出代理合作方案：基礎底價 + 超量獎金佣金
4. 從非獨家開始，跑通後再升級為區域獨家

### 代理商合作條款框架
```
• 銷售底價：[BASE_PRICE]元/噸（代理商自行定價給客戶）
• 代理商利潤空間：[AGENT_MARGIN]元/噸（含在底價外的建議售價中）
• 月最低銷售量：[MIN_MONTHLY_VOLUME]噸（以享獨家資格）
• 樣品支持：首批[SAMPLE_QTY]kg免費提供
• 市場資料支持：提供本套行銷包（翻譯為客戶需要語言）
```
