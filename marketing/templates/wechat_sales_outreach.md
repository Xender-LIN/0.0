## 脚本 A｜工厂采购主管版

### 第1条（加好友后立即发）
```
您好！我是Xender LIN，台湾泳鉅鑫再生塑料的销售。

看到您在[MARKET_NAME]做塑料原料采购，想跟您介绍一下我们的再生PC颗粒——台湾生产，每批SGS检测，品质稳定。

请问您工厂目前有在用再生PC料吗？
```

### 第2条（对方回复"有"或"在看"后）
```
太好了！方便透露一下目前用的是哪个等级吗？（MFI区间、颜色、用途）

我们有光学级、电子级、通用级和改性级（汽车）四个等级，可以针对您的应用推荐最适合的。

另外，我们每批都出SGS第三方检测报告，可以直接发给您参考。
```

### 第3条（发产品资料时）
```
这是我们的产品规格表，您可以看一下：
[附：pc_pellets_spec.md导出的PDF版]

主要参数：
• MFI：8-22 g/10min（按等级）
• 密度：1.19-1.21 g/cm³
• 拉伸强度：≥55 MPa
• 热变形温度：≥120°C

请问您目前用量大概是多少？我根据数量给您报价。
```

### 第4条（询价后报价）
```
根据您 [ORDER_QTY] 吨的需求，[GRADE_NAME] 等级报价如下：

• 价格：[PRICE_RANGE] 元/吨
• 含量：PC≥[PC_CONTENT]%
• 交货期：台湾发货后约[DELIVERY_DAYS]个工作日到[DESTINATION]
• 付款：[PAYMENT_TERMS]

您这边方便先要5kg样品试机吗？样品我们承担快递费。
```

### 第5条（样品寄出后跟进）
```
[CUSTOMER_NAME]您好，样品已通过顺丰发出，单号：[TRACKING_NUMBER]

预计[DELIVERY_DATE]到您那边。

样品收到后有任何问题欢迎直接联系我，我们的技术支持也可以视频通话协助您试机。
```

### 第6条（样品收到后3天跟进）
```
您好，样品应该收到了，请问试机结果怎么样？

如果需要调整MFI或颜色，我们可以根据您的要求定制。
```
