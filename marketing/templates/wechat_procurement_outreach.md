
## 脚本 C｜工厂废料部门版（直接从工厂收边角料）

### 第1条（联系工厂废料处理部门）
```
您好！我是台湾泳鉅鑫再生塑料的采购Xender LIN。

想了解一下贵工厂在生产过程中是否有PC材质的边角料/废品料需要处理？

我们可以：
• 上门收购，省您处理麻烦
• 价格比废料商更好（减少中间环节）
• 可以开发票，配合贵公司的废料处置合规流程

请问您们工厂每月大概有多少PC废料？
```

### 第2条（了解工厂废料情况）
```
了解，这类边角料我们是可以收的。

为了给您准确报价，能否提供一下：
1. 废料的产品类型（手机壳/家电件/汽车件/其他？）
2. 大概的PC含量比例（纯PC还是混料？）
3. 每月产生量
4. 目前是怎么处理的（卖给废料商/自行处理？）

这些信息帮助我们评估是否适合纳入我们的收购体系，也方便给您一个合理的价格。
```

### 第3条（提供合规支持）
```
我们在大陆有合规的废料进出口渠道，所有收购均可提供：

✓ 正规收购合同（配合您公司的废料处置备案）
✓ 收购收据/发票（配合财务合规）
✓ 最终处置证明（配合环保检查要求）

如果贵公司有ISO 14001环境管理体系认证，我们的合规文件也可以配合您的审核需求。

方便留一个邮箱，我发完整的合作方案给您？
```
